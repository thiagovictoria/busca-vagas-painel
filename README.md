# Painel de vagas

Página do painel de acompanhamento de vagas. Contém só o código da página: os dados ficam no Supabase,
acessíveis apenas com login (cadastro de novos usuários desligado e RLS ativo).

A chave que aparece no `index.html` é a chave **publicável** do Supabase, feita para ficar em páginas públicas.

O código-fonte principal (coleta, match e este painel) fica no repositório privado `busca-vagas`, em `painel/index.html`.
